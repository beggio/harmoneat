# HarmoNeat — Beta Test Build

Thanks for trying this out! A few things before you dive in.

## This is pre-production software

HarmoNeat is under active development. Expect bugs, missing features, and
things changing between versions — including, occasionally, your saved
data's format. Don't rely on it yet for anything you can't afford to lose.

## Running it

No installer — just unzip this folder wherever you like and run
`harmoneat.exe`. Nothing else needs to be installed.

## Sending feedback

This build has an in-app feedback system:

- **Settings → Beta Testing → Send Feedback** — type anything: bugs,
  confusing bits, ideas, typos. It's sent straight to the developer along
  with your app version, OS, and what features you've used, so there's
  context without you having to explain your setup.
- **Crashes are reported automatically** — if the app hits an unexpected
  error, a report is sent the same way. No action needed from you.
- If you're offline when you send feedback, it's saved locally
  (`beta_submissions.log` in the app's data folder) and nothing is lost —
  just resend it once you're back online, or let the developer know it's
  sitting there.

## What to try

- Create a note, record or import some audio
- Build a guitar tab, a chord chart, and a notation sheet for the same note
- Poke around Resources (Circle of Fifths, the chord reference chart)
- Try the different color schemes and large-print toggle in Settings

Whatever you find — works great, confusing, broken — is useful feedback.
Thanks again for testing!
